# 🎓 ScholarStream

A modern Scholarship Management Platform that helps students discover, apply for, and manage scholarship opportunities from universities around the world.

🔗 **Live Site:** https://scholarstream-a11.web.app/

---

## 📖 Project Overview

ScholarStream is a full-stack scholarship management system designed to simplify the scholarship application process. Students can browse scholarships, submit applications, make payments, write reviews, and track their application status. Administrators and Moderators can efficiently manage scholarships, users, reviews, and applications through a role-based dashboard.

---

## ✨ Key Features

### 🌍 Public Features

* Browse all available scholarships
* Search scholarships by name, university, or degree
* Filter scholarships by category, subject, and location
* View detailed scholarship information
* Contact support through a dedicated form
* Responsive design for mobile, tablet, and desktop devices

### 👨‍🎓 Student Dashboard

* View personal profile
* Apply for scholarships
* Pay application fees using Stripe
* Track application status
* Manage submitted applications
* Add reviews after application completion
* Edit and delete personal reviews
* View payment history

### 🛡️ Moderator Dashboard

* Manage all scholarship applications
* Provide feedback to applicants
* Update application status
* Reject applications when necessary
* View and moderate all reviews

### 👑 Admin Dashboard

* Add new scholarships
* Update scholarship information
* Delete scholarships
* Manage platform users
* Promote or demote user roles
* View analytics and platform statistics
* Monitor scholarship categories and application trends
